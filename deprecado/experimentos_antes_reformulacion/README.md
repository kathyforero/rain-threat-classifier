Experimentos previos a la reformulación del pipeline.

Esta carpeta conserva las pruebas V1–V5 desarrolladas durante
la fase exploratoria del proyecto.

Incluye:
- datasets derivados;
- ingeniería de características experimental;
- selección de características;
- modelos entrenados;
- tuning de hiperparámetros;
- resultados de validación.

Estos archivos se conservan únicamente por trazabilidad y NO
forman parte del pipeline reproducible final.

La rama oficial del proyecto fue reiniciada después de la
construcción y validación del dataset meteorológico base.
