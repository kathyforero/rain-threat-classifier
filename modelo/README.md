# Modelo

Modulo de machine learning del proyecto.

Contiene pasos ejecutables del pipeline:

- descarga de ERA5-Land;
- construccion de indicadores;
- auditoria de calidad;
- preparacion del dataset supervisado;
- construccion de features candidatas.

Tambien contiene notebooks para:

- analisis de caracteristicas;
- comparacion de modelos;
- validacion temporal;
- evaluacion final.

Ejecutar siempre desde la raiz del proyecto cuando sea posible.
